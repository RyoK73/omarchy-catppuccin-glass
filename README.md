# omarchy-glass-theme

A glassmorphism-inspired theme for [omarchy](https://github.com/basecamp/omarchy) — featuring translucent surfaces, soft blur effects, and a modern dark aesthetic.

## About

This theme is built for the [omarchy](https://github.com/basecamp/omarchy) theme system created by DHH / Basecamp. It customizes the visual appearance across all major desktop components with a unified glass-like style.

## Components

- **Hyprland** — window manager
- **Hyprlock** — lock screen
- **Waybar** — status bar
- **Mako** — notifications
- **Ghostty** — terminal
- **Neovim** — editor
- **Starship** — shell prompt
- **SwayOSD** — volume / brightness OSD
- **Walker** — application launcher
- **btop** — system monitor

## Installation

1. Open the Omarchy menu (`Super + Alt + Space`)
2. Navigate to **Install → Style → Theme**
3. Enter the repository URL:
   ```
   https://github.com/RyoK73/omarchy-catppuccin-glass
   ```

You can also apply the theme programmatically with `omarchy-theme-set`.
